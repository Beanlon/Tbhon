Users can upload or capture images of durian trees via the mobile application, which then sends the image to the Flask server for processing using the PyTorch and YOLOv5 models. The models classify the disease present in the image and generate a new image with bounding boxes around the identified objects. The results are then returned to the mobile app and displayed to the user in a visualized format.  To achieve the first objective, the study utilized the Python programming language, Roboflow framework for Computer Vision, and PyTorch machine learning library for training and integrating the algorithm into the mobile application. Finally, the results obtained from the algorithm were stored in a Firebase database for future use.

To achieve this objective, the researchers first needed to create a dataset of durian images and augment it to increase the diversity and size of the dataset. They used several image augmentation techniques such as rotating, flipping, and adjusting brightness and saturation to create variations of the original images. They employed Roboflow, an online toolkit that provides pre-processing and augmentation tools, to enhance the quality of the dataset further.  After creating the dataset, the researchers utilized YOLOv5, which uses a deep CNN called CSPNet, to detect objects in the images. The model works by predicting bounding boxes for objects within each cell of a grid applied to the image and class probabilities for each object within the bounding box. The researchers employed anchor boxes, pre-defined bounding boxes of different sizes and aspect ratios, to improve the accuracy of object localization. YOLOv5 also used various data augmentation techniques to improve the model's robustness to different image conditions and object orientations.  In summary, the researchers achieved the objective of identifying a disease from Durian images by creating and augmenting a dataset, utilizing YOLOv5, and employing various techniques to improve the model's accuracy and robustness. The use of data augmentation techniques, pre-processing and augmentation tools provided by Roboflow, and anchor boxes in YOLOv5 helped achieve this objective.

These values indicate that the model has varying levels of success in correctly identifying the presence or absence of durian patch canker or other diseases in different images. It is important to note that, in general, recall values tend to be lower than precision values when detecting objects in images. This is because it is often more challenging to identify all instances of a particular object than to correctly classify the objects that have been found.
